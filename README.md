# World Flag Country Quiz

## 概要
30カ国の国旗をcanvasで描画し、国名を4択クイズで当てるゲーム。地域フィルタ（アジア/欧州/南北米/アフリカ/オセアニア）とストリーク記録付き。

## 機能
- 30カ国の国旗をcanvasで描画
- 4択クイズ形式
- 地域フィルタ（全地域/アジア/欧州/南北米/アフリカ/オセアニア）
- スコア・連続正解数（ストリーク）の記録
- 正解・不正解のハイライトフィードバック

## 使い方
地域フィルタボタンで対象地域を選択し、表示された国旗の国名を4つの選択肢から選んでください。「Skip」ボタンで次の問題に進めます。
